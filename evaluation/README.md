# DPDP privacy gateway evaluation

The evaluator uses the synthetic corpus in `dataset/synthetic_documents.json`
(50 documents, 240 annotated entity spans). `dataset/ground_truth.json` is a
separate wrapped copy and is not loaded by the current evaluator.

## Modes

Run the offline reference simulator:

```powershell
python evaluation/evaluate.py --mode reference
```

Reference results are labeled **Reference simulation — not live backend
measurements**. The simulator copies PERSON and ADDRESS spans from the dataset
annotations; its scores do not measure backend NER accuracy. It makes no Groq
requests. Reference latency and live request trend are not measured.

Live evaluation is opt-in. Start the FastAPI backend first, then explicitly
specify a limit and confirmation:

```powershell
python evaluation/evaluate.py --mode live --limit 5 --confirm-live
```

This sends at most five synthetic documents to `/api/process`; each successful
request may make one Groq request. Use a limit from 1 through 50. Failures are
recorded as failed documents; the evaluator never substitutes reference output
for a failed live request. A partial run has status `failed`, not `completed`.
Opening the frontend does not execute this script or make provider calls.

The script writes results to `evaluation/results.json` and
`frontend/public/evaluation-results.json`. Live runs replace those files, so
preserve any result you need before launching one. Results identify their mode
and source. Do not present reference scores as live detector measurements.

## Metrics

- Entity precision, recall and F1 use exact `(type, start, end)` spans. Duplicate
  annotations/predictions are counted rather than discarded.
- Raw PII leakage checks ground-truth entity values against each successful
  sanitized response. `raw_pii_leakage_count` counts documents where one or
  more values matched or the backend reported leakage, not individual values.
- Reinsertion accuracy requires the backend to list a placeholder in
  `restoration.restored` and requires that placeholder to be absent from the
  final response. A dropped placeholder does not count as restored.
- Latency is taken from the backend response only in live mode.
- No request trend or outbound pass/block count is inferred from this dataset.

The corpus is synthetic, generated by `dataset/generate_dataset.py`, and is not
represented as organizer-provided data.
