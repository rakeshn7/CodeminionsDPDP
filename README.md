# DPDP-Ready Privacy Gateway

This repository contains the React dashboard and synthetic demo fixtures for the DPDP-Ready Privacy Gateway.

## Organizer materials inspected

The currently supplied links are reference materials, not an annotated PII test corpus:

- [MeitY Digital Personal Data Protection Rules, 2025](https://www.meity.gov.in/documents/act-and-policies/digital-personal-data-protection-rules-2025-gDOxUjMtQWa) — rules reference; the page was not accessible to the inspection fetcher (HTTP 403).
- [Gazette Notification G.S.R. 843(E)](https://egazette.gov.in/WriteReadData/2025/267647.pdf) — PDF notification concerning commencement dates; it does not provide document-level PII ground truth.
- [Microsoft Presidio supported entities](https://github.com/microsoft/presidio/blob/main/docs/supported_entities.md) — Markdown reference describing recognizer categories; it does not provide annotated documents.

No organizer-provided corpus, entity annotations, or character offsets were present in the workspace or common Downloads/Desktop/Documents folders. The `dataset/synthetic_documents.*` and `dataset/ground_truth.json` files are fixtures generated by the earlier demo task; they are not organizer data and must not be used to claim organizer-dataset performance.

## Current evaluation status

Evaluation is **not yet available**. The FastAPI backend was not running at `localhost:8000`, so `/docs`, `/openapi.json`, and `/health` could not be inspected. Ground-truth comparison, leakage checks against actual outbound payloads, reinsertion checks, and measured latency require the organizer's test corpus and an available backend. The dashboard intentionally reports unavailable results instead of showing the earlier illustrative metrics.

Do not add organizer data to Git unless its distribution terms explicitly permit it. Keep any local corpus outside the repository or in an ignored location, and process its text only through the local privacy gateway.

## Frontend setup

```bash
cd frontend
npm install
cp .env.example .env
npm run dev -- --host 0.0.0.0
```

Set `VITE_API_URL` to the FastAPI base URL. The existing process client uses the previously agreed target `POST /api/process` request (`text`, `task`, `provider`), but this contract has not been verified against a running backend. Confirm it against Person 1's `/docs` before evaluating organizer documents.
